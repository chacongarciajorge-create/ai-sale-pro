# AI Sales Pro

AI-powered customer conversion and follow-up system for small businesses.

This skill provides a 24/7 AI sales assistant that captures, qualifies, and converts leads automatically for contractors, restaurants, and cafes.

## Installation
```bash
npx skills add ai-sales-pro
```

## Features
- Chat widget for websites
- SMS lead capture
- Instant appointment booking
- Missed call text back
- Automated follow-ups
